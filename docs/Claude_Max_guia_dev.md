# Plan Claude Max — Guía de capacidades para desarrollo

> Cuenta: plan **Max** (individual) de Jaime Tovar.
> Verificado contra el Centro de Ayuda de Claude y contra lo habilitado en la cuenta el **10 de octubre de 2026**.

## 0. Resumen ejecutivo

1. El plan Max tiene **dos presupuestos independientes**: uso interactivo y créditos API mensuales.
2. Lo que se opera a mano consume el plan; lo que el sistema ejecuta solo consume créditos API.
3. La forma correcta de trabajar es vincular una organización de Claude Console al plan.

## 1. Qué incluye el plan Max

| Concepto | Detalle |
|---|---|
| Niveles | Max 5x ($100 USD/mes) y Max 20x ($200 USD/mes) |
| Capacidad | 5x o 20x la asignación por sesión del plan Pro |
| Límite por sesión | Se reinicia cada 5 horas |
| Créditos API | $100 o $200 USD/mes según nivel |
